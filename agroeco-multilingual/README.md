# Agroeco Multilingual

Легкий плагін багатомовності для WordPress, який замінює **WPML Multilingual CMS** і **WPML Flag in Menu Extended**.

Головна ідея: плагін **працює безпосередньо з таблицями WPML** (`wp_icl_translations`, `wp_icl_languages`,
`wp_icl_strings` тощо). Нічого не мігрується і не копіюється: усі сторінки, записи, рубрики, меню й перекладені
рядки, створені у WPML, одразу підхоплюються. Якщо колись знадобиться повернутися на WPML, дані лишаються в
тому самому форматі.

## Можливості

| Функція | Як працює |
| --- | --- |
| Мовні URL | `site/en/page/` (каталог), `site/page/?lang=en` (параметр) або окремий домен на мову. Налаштування переносяться з WPML. |
| Однакові slug різними мовами | `/about/` і `/en/about/`, зокрема дочірні сторінки (`/en/about/team/`). |
| Фільтрація контенту | Записи, сторінки, власні типи записів, рубрики, мітки, архіви, пошук, сусідні записи показуються лише поточною мовою. |
| Статична головна і сторінка блогу | Автоматично підставляються перекладені сторінки. |
| Меню | Для кожної мови показується перекладене меню (зв'язки з WPML зберігаються). |
| Перемикач із прапорами в меню | Замість WPML Flag in Menu Extended: випадне меню або пункти в рядок; прапор, назва мови, код. |
| Шорткод і функція шаблону | `[agml_language_switcher]`, `agml_language_switcher()`. |
| SEO | Теги `hreflang` (+ `x-default`), правильний `<html lang>`, локаль WordPress для кожної мови. |
| Рядки (String Translation) | Назва й опис сайту, заголовки віджетів, рядки теми (`__()`, `_e()`) із перекладами з WPML. |
| API WPML для тем | `icl_object_id()`, `icl_get_languages()`, `icl_t()`, `ICL_LANGUAGE_CODE`, фільтри `wpml_object_id`, `wpml_current_language`, `wpml_active_languages`, `wpml_translate_single_string` та ін. Тема, написана під WPML, працює без змін. |
| Адмінка | Перемикач мови контенту в адмін-панелі, колонка «Мови» з прапорами (редагувати / «+» створити переклад), метабокс «Мова», мови для рубрик і меню, сторінка «Налаштування → Мови сайту». |

## Перехід із WPML

1. **Зробіть резервну копію бази даних.**
2. Скопіюйте папку `agroeco-multilingual` у `wp-content/plugins/`.
3. **Деактивуйте** (але *не видаляйте*) плагіни *WPML Multilingual CMS*, *WPML String Translation*,
   *WPML Flag in Menu Extended* та інші доповнення WPML. Таблиці `icl_*` при деактивації залишаються.
4. Активуйте **Agroeco Multilingual**. Під час активації:
   - мова за замовчуванням, формат URL, домени, перекладні типи записів і таксономії переносяться з налаштувань WPML;
   - використовувані прапори копіюються з папки WPML у `wp-content/uploads/agroeco-multilingual/flags/`,
     тож вони лишаться доступними навіть після видалення WPML.
5. Відкрийте **Налаштування → Мови сайту**, позначте розташування меню, куди додавати перемикач мов із
   прапорами (це замінює WPML Flag in Menu Extended), та оберіть вигляд.
6. Перевірте сайт. Після цього WPML можна видалити. Плагін WPML під час видалення може запропонувати стерти свої
   дані: не погоджуйтеся, бо переклади зберігаються саме там.

Поки WPML активний, Agroeco Multilingual нічого не робить і лише показує попередження. Так обидва плагіни не
конфліктують.

## Робота з перекладами

- **Створити переклад:** у списку записів/сторінок натисніть приглушений прапор зі знаком «+». Буде створено
  чернетку перекладу з копією вмісту, мета-полів (мініатюра, поля ACF, налаштування конструктора сторінок) та
  перекладених рубрик. Перекладіть текст і опублікуйте.
- **Мова контенту в адмінці:** перемикач у верхній панелі (або посилання над списком записів). Нові записи,
  рубрики й меню отримують вибрану мову. «Усі мови» показує все.
- **Рубрики й мітки:** колонка «Мови» в списку термінів, поле «Мова» у формі; «+» відкриває форму додавання вже
  прив'язану до оригіналу.
- **Меню:** на сторінці «Вигляд → Меню» є блок «Мова меню»: мова поточного меню та вибір меню-перекладів.
  Розташування меню в темі призначайте для меню основної мови, а переклади підставляться автоматично.

## Перемикач мов у шаблоні

```php
<?php agml_language_switcher( array(
    'style'        => 'dropdown', // list | dropdown
    'flags'        => 1,
    'names'        => 'native',   // native | translated | both | code | none
    'hide_current' => 0,
    'skip_missing' => 0,          // 1 — не показувати мови без перекладу сторінки
) ); ?>
```

```
[agml_language_switcher style="list" flags="1" names="code"]
```

Якщо перекладу поточної сторінки немає, посилання веде на головну сторінку відповідної мови.

CSS-класи: `.agml-menu-item`, `.agml-lang-en`, `.current-lang`, `.agml-flag`, `.agml-name`, `.agml-switcher`.
До `<body>` додається клас `lang-uk` / `lang-en`.

## Хуки для розробників

- `agml_loaded` (action): плагін ініціалізовано, аргумент — екземпляр `AGML_Plugin`.
- `agml_active_languages` (filter): масив активних мов.
- `agml_language_links` (filter): посилання перемикача мов.
- `agml_translation_created` (action): `$new_id, $original_id, $lang`.
- У `WP_Query` / `get_terms()` можна передати `'lang' => 'en'` або `'lang' => 'all'`.
  Як і у WPML, `get_posts()` за замовчуванням має `suppress_filters => true` і повертає записи всіма мовами.

## Обмеження порівняно з WPML

- Немає модуля Translation Management (черги, перекладачі, редактор перекладів WPML), автоматичного
  перекладу та інтерфейсу редагування рядків. Уже перекладені рядки працюють, нові можна додати в таблицю
  `icl_string_translations` або через `icl_register_string()`.
- Режим «показувати оригінал, якщо перекладу немає» для типів записів не підтримується: запис без перекладу
  не показується іншою мовою.
- Медіафайли (вкладення) спільні для всіх мов.
- WooCommerce Multilingual, переклад слагів типів записів і перенаправлення за мовою браузера не реалізовані.
